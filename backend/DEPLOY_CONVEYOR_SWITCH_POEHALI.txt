## Часть 2 — 146 отправлений OZON в «Готовые» без начислений

Только если V0699 ещё не гоняли. Если уже закрыли эти 146 — пропусти часть 2.

Файл: `db_migrations/V0699__close_ozon_assembly_146_ready_no_pay.sql`

Сначала SELECT по 146 номерам отправления из файла
(`order_number` / `ozon_posting_number`):

- сколько нашлось (должно быть 146; меньше — стоп и список пропавших);
- сколько уже «Готовые» / «Со склада» / «Отменён»;
- сколько в «Раскроено» (~40 кроила другая смена);
- сколько уже имеют расход ткани (тюль);
- сколько раскроены без расхода.

Потом выполни файл КАК ЕСТЬ. Не переписывай, не добавляй `salary_accruals`,
не создавай `goods_warehouse`.

Ткань: только тюль. Если расход уже есть — не списывать второй раз.
Уже раскроенные без расхода — с рулонов смены закройщика.
Ещё не кроили — с сегодняшней смены.
Не хватает ткани — ОСТАНОВИСЬ, пришли ошибку, не повторяй.

После: сколько ушло в «Готовые», сколько нового расхода, с каких смен,
подтверждение что начислений не создавали.
