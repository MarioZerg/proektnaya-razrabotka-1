Ты — агент деплоя на poehali.dev. Проект CRM «Мегатюль».
Новых Cloud Functions не создавай. Обнови три существующие функции.
URL всех функций после публикации должны остаться ПРЕЖНИМИ.
Секреты не меняй и не ротируй.

Зачем: на сайте мегатюль.рф доставка до Москвы у «Молнии» одна и та же
(230 ₽) и для ширины 200, и для 800. В карточках товаров не было габаритов
и веса упаковки. Теперь они хранятся по каждому товару, подтягиваются из
карточек OZON и уходят на сайт.

## 1) Миграция

Применить `db_migrations/V0791__item_package_dims.sql` — добавляет в
marketplace_items колонки pack_length_mm, pack_width_mm, pack_height_mm,
pack_weight_g, pack_source, pack_updated_at. Только ADD COLUMN IF NOT EXISTS.

## Проверка после деплоя

1. Справочник товаров → вкладка МЕГАТЮЛЬ → «Синхронизировать».
   В сообщении должно быть «Габариты упаковки с OZON обновлены: N».
2. Открой карточку «Молния 800×260» на вкладке мегатюль.рф — в блоке
   «Упаковка для доставки» должны стоять длина, ширина, высота и вес,
   подпись «Подтянуто из карточки OZON».
