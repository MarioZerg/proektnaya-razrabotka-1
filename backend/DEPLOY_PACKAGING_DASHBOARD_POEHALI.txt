## Часть B — что должно быть в коде

### B1. shipments — упаковка без смены
Заявка/выдача/приём: все позиции «Упаковка» → `shift_number = NULL`.

### B2. rolls — упаковщик видит пул цеха
Роли packer / packer_returns: рулоны упаковки без фильтра по смене.

### B3. kiosk — списание упаковки FIFO по цеху
`write_off_packaging` без привязки к номеру смены.

### B4. reviews — привязка WB + статус + список
`backend/reviews/index.py`:

- сохранять `wb_srid` и `wb_order_status` из отзыва WB (`orderStatus`:
  buyout / returned / rejected / notSpecified);
- backfill `orders.wb_rid` за ~365 дней (до 20 страниц заданий);
- `rematch_wb_reviews`: связка по `wb_rid = wb_srid`, по `wb_order_id`,
  по `order_number`, плюс когда номер = id задания;
- при синке дописывать srid/заказ/статус уже существующим отзывам;
- GET list отдаёт `wbSrid`, `wbRid`, `wbOrderStatus`, имена
  закройщик/швея/упаковщик.

После публикации reviews прогони sync до `done: true` (кнопка
«Обновить отзывы» в CRM). В ответе смотри `unmatchedWb` — должно падать.
