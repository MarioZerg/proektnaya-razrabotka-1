Ты — агент деплоя на poehali.dev. Проект CRM «Мегатюль».
Новых Cloud Functions не создавай. Миграций нет — колонки упаковки уже есть.
URL функции после публикации должен остаться ПРЕЖНИМ. Секреты не меняй.

Зачем: габариты и вес упаковки есть на карточках маркетплейсов (OZON), а на
товары интернет-магазина мегатюль.рф их приходилось бы вписывать вручную.
Теперь одна кнопка переносит упаковку на все товары сайта и сразу отправляет
её на сайт — по ней сайт считает цену Ozon Доставки для каждого размера.

## 1) Функция site_orders

**URL (не менять):** https://functions.poehali.dev/dbc4d229-e722-40bc-aa47-f47bed23dab5
Залей пакет `backend/site_orders/` целиком (index.py, site_catalog.py,
site_chats.py, requirements.txt — не урезай).
Новое действие { action: 'copy_packages' } — только администратор:
- берёт упаковку того же артикула с карточек маркетплейсов (mol2_230 = mol2_230);
- если такой высоты на маркетплейсе нет — ту же ткань и ширину с ближайшей
  высотой (pack_source = 'ozon_near');
- вписанное вручную (pack_source = 'manual') не трогает;
- отправляет на сайт ВСЕ товары с упаковкой (POST /api/crm/prices с package).
Ответ: { changed, exact, near, missing, withPackage, pushed, pushError }.

## Проверка после деплоя

1. Магазин мегатюль.рф → товары: вверху справа кнопка «Упаковка с маркетплейсов»
   (видна администратору).
2. Нажми её. Сообщение: «Упаковка перенесена и отправлена на сайт», сколько
   обновлено, сколько с упаковкой на сайте и сколько не нашлось.
3. Раскрой «Молния», ширина 200 — у «Упаковка» стоят габариты и вес,
   подпись «с OZON» или «с OZON, по соседней высоте».
