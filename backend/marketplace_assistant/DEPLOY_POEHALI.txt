# Деплой МЕГАМАГ + МЕГАБУХ на Поехали

Сделай на poehali.dev ровно это. Фронт в CRM уже готов — без публикации функций чаты
не получат новые возможности.

---

## 1) Функция МЕГАМАГ — marketplace_assistant

**URL (уже в CRM):**
https://functions.poehali.dev/031fc26f-9279-450e-a606-c662b07fe128

**Что загрузить из репозитория:**
- `backend/marketplace_assistant/index.py`
- `backend/marketplace_assistant/knowledge.py`
- `backend/marketplace_assistant/docs_index.py` (если есть в проекте функции)
- `backend/marketplace_assistant/requirements.txt`

**Как опубликовать:**
1. Открой проект → Cloud Functions → функция `marketplace_assistant`
   (или та, чей URL `031fc26f-9279-450e-a606-c662b07fe128`).
2. Замени код файлами из папки выше (весь пакет функции, не только кусок промпта).
3. Нажми **Сохранить** → **Опубликовать / Deploy**.
4. Убедись, что URL после публикации тот же. Если URL сменился —
   обнови `MARKETPLACE_ASSISTANT_URL` в `src/lib/marketplaceAssistantApi.ts`.

**Секреты / переменные окружения (должны быть):**
- `DATABASE_URL` — Postgres (функция работает READ ONLY)
- `API_KEY_MEGAMAG` — ключ AITUNNEL для МЕГАМАГа (или запасной `AITUNNEL_API_KEY`)
- по желанию: `MAIN_DB_SCHEMA`, `AITUNNEL_MODEL`, `MEGAMAG_REASONING`

**Системный промпт в UI Поехали НЕ вставляй отдельно.**
Промпт уже внутри `index.py` (`SYSTEM_PROMPT` + блоки обучения).
Файл `PROMPT_POEHALI.txt` — только шпаргалка; для облачной функции источник правды — код.

**Что появится после деплоя МЕГАМАГа:**
- образовательный центр (docs.ozon.ru, seller.wildberries.ru/instructions, partner.market.yandex.ru)
- чтение файлов/выгрузок (Excel, CSV, PDF, фото)
- карточки штор/тюля + аналитика продаж
- сравнение с конкурентами (таблица + рекомендации + 3 названия / 1 описание)
- доступ админу (role admin) к чату — полный, как менеджеру
- статусы «Пошёл смотреть информацию: …ссылка…»

## 2) Функция МЕГАБУХ — ai_assistant

**URL (уже в CRM):**
https://functions.poehali.dev/c6f2fe80-681d-438f-85c6-f30503927ede

**Что загрузить:**
- `backend/ai_assistant/index.py`
- `backend/ai_assistant/business_memory.jsonl` (если функция его читает с диска)
- `backend/ai_assistant/requirements.txt`

**Как опубликовать:**
1. Открой функцию `ai_assistant` (URL `c6f2fe80-681d-438f-85c6-f30503927ede`).
2. Залей обновлённый код.
3. **Сохранить** → **Опубликовать**.

**Секреты:**
- `DATABASE_URL`
- ключ ИИ (тот, что уже стоит у МЕГАБУХа / AITUNNEL)

**Зачем деплоить МЕГАБУХа сейчас:**
- админ из меню «Агенты» может открыть МЕГАБУХ и писать (как бухгалтер)
- в контексте собеседника теперь Имя + Фамилия

---

## 3) Что НЕ трогать

- Не создавай новые функции «с нуля», если старые URL уже прописаны во фронте —
  обновляй существующие.
- Не копируй промпт только в поле System Prompt агента Поехали и не жди,
  что облачная функция его подхватит — у нас промпт в коде функции.
- Не меняй ключи маркетплейсов в CRM: МЕГАМАГ читает их из `marketplace_integrations`.

---

## 4) Проверка после публикации

1. Зайти в CRM под **админом** → меню **Агенты** → МЕГАМАГ / МЕГАБУХ открываются.
2. МЕГАМАГ: спросить «требования к карточке на OZON» —
   должен искать справку и в статусе показать ссылку docs.ozon.ru / seller-edu.
3. МЕГАМАГ: приложить маленький Excel/CSV — отвечает по выгрузке.
4. МЕГАМАГ: написать сообщение — подпись пользователя **Имя Фамилия**.
5. Менеджер → МЕГАМАГ как раньше; бухгалтер → МЕГАБУХ как раньше.

Если «Failed to fetch» / таймаут — функция не опубликована или шлюз рвёт долгий ответ;
повтори короткий вопрос и проверь, что Deploy прошёл успешно.
