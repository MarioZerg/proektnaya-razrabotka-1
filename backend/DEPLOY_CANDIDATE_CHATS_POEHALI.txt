Ключи Авито в переменные окружения НЕ клади. Функция читает их из таблицы
`marketplace_integrations`: магазин включён, `marketplace_code = 'avito'`,
в credentials поля `clientId` и `clientSecret`. Это экран
«Настройки → Интеграции → Avito».

**Что публикуется**

GET `?candidateChats=1` — список диалогов. Только `require_admin`.
GET `?candidateChat=<id>&live=1` — переписка, при открытии дочитывает Авито.
GET `?candidateChat=<id>&live=0` — только то, что уже в базе. Экран опрашивает это каждые 15 секунд.
POST `{ action: 'candidate_chats_sync' }` — забирает чаты вакансий и подписывает webhook.
POST `{ action: 'candidate_chat_send', chatId, text }` — ответ в Авито, до 1000 символов.
POST `{ action: 'candidate_chat_status', chatId, status }` — статус:
`new`, `selected`, `meeting`, `rejected`.
POST без action с телом webhook Авито (`payload.type = message`) — входящее сообщение, без токена сотрудника.
POST `{}` — проверка адреса Авито, ответ 200.

Webhook URL уже зашит в код и равен URL этой же функции. Не подставляй другой адрес.

В базу попадают только чаты по вакансиям: в ссылке объявления есть `/vakansii/`
или в названии есть «шве», «закрой», «бухгалтер», «вакан». Чаты покупателей тюля не сохранять.

Таблицы, которые функция создаёт сама:
- `avito_candidate_chats` (в том числе колонка `status`, по умолчанию `new`)
- `avito_candidate_messages`

Повторная синхронизация не сбрасывает `status` и не шлёт повторное уведомление,
если `notified_at` уже заполнен. Старые диалоги старше 20 минут при первой
синхронизации в MAX не дублировать.

**MAX.** Письмо «Кандидат написал на Авито» только пользователям, у которых
в `user_roles` есть утверждённая роль `admin`, аккаунт активен, не в архиве,
и заполнен `max_user_id`. Менеджерам, швеям и остальным не писать.
Заголовок `Authorization: <MAX_BOT_TOKEN>` без Bearer.
SSL через `russian_ca.ca_bundle()` (certifi + сертификат Минцифры).
Ошибку отправки в MAX глушить: диалог уже сохранён, откатывать его нельзя.

## 3) Проверка после публикации

1. Функция users отвечает по старому URL, список сотрудников на месте.
2. Админ открывает «Пользователи» и видит вкладку «Чаты с кандидатами».

   текстом «Подключите Avito в настройках интеграций», а не падением функции.
5. Пустой POST `{}` на функцию users возвращает 200, а не «Неизвестное действие».
