СБОРКА APK-ФАЙЛА ПРИЛОЖЕНИЯ «МЕГАТЮЛЬ»

Файл сценария нужно создать вручную на сайте github.com — папка .github
не переносится из системы автоматически.

ЧТО ДЕЛАТЬ
1. Откройте свой репозиторий на github.com
2. Нажмите «Add file» -> «Create new file»
3. В поле имени файла вставьте ровно эту строку:
      .github/workflows/build-apk.yml
   (косые черты сами создадут нужные папки)
4. Скопируйте в тело файла всё, что идёт ниже длинной линии
5. Внизу страницы нажмите зелёную кнопку «Commit changes»
6. Откройте вкладку Actions — вместо «Get started» слева появится «Сборка APK»
7. Нажмите на неё -> справа кнопка «Run workflow» -> ещё раз «Run workflow»
8. Через 5-10 минут откройте завершённую сборку, промотайте вниз до раздела
   Artifacts и скачайте megatul-apk — внутри файл app-debug.apk

ВАЖНО ПРИ КОПИРОВАНИИ: отступы в начале строк обязательны, их нельзя менять.

--------------------------------------------------------------------------

name: Сборка APK
on:
  workflow_dispatch:
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
      - uses: actions/setup-java@v4
        with:
          distribution: 'temurin'
          java-version: '17'
      - uses: android-actions/setup-android@v3
      - run: npm install --legacy-peer-deps
      - run: npm run build
      - run: npm install --no-save --legacy-peer-deps @capacitor/core@6 @capacitor/cli@6 @capacitor/android@6
      - run: |
          cat > capacitor.config.json << 'EOF'
          {"appId":"ru.yarplan.megatul","appName":"МЕГАТЮЛЬ","webDir":"dist","server":{"androidScheme":"https"}}
          EOF
      - run: npx cap add android && npx cap sync android
      - run: cd android && chmod +x gradlew && ./gradlew assembleDebug --no-daemon
      - uses: actions/upload-artifact@v4
        with:
          name: megatul-apk
          path: android/app/build/outputs/apk/debug/app-debug.apk
