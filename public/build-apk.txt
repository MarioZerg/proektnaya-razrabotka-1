СБОРКА APK ПРИЛОЖЕНИЯ «МЕГАТЮЛЬ» ДЛЯ RUSTORE

ВАЖНО. Для RuStore нужен ПОДПИСАННЫЙ файл (release). Неподписанный debug-файл
магазин не примет — он годится только для установки на свои планшеты вручную.

=========================================================================
ЧАСТЬ 1. СОЗДАЁМ КЛЮЧ ПОДПИСИ (делается один раз)
=========================================================================

Ключ — это ваша подпись разработчика. ЕГО НЕЛЬЗЯ ТЕРЯТЬ: без него вы не
сможете выпускать обновления приложения, придётся публиковать заново.

Нужен компьютер с установленной Java. Проверить: откройте командную строку
и введите   keytool -help   — если пишет справку, Java есть.

Выполните команду (одной строкой):

keytool -genkeypair -v -keystore megatul.keystore -alias megatul -keyalg RSA -keysize 2048 -validity 10000

Программа спросит:
  - пароль хранилища — придумайте и ЗАПИШИТЕ
  - имя, организацию, город, страну — можно вводить как есть (или Enter)
  - в конце подтвердите: yes

Появится файл megatul.keystore. Сохраните его в надёжном месте.

Теперь превратите файл в текст (нужно для GitHub). В командной строке:

  Windows:  certutil -encode megatul.keystore keystore.txt
  Mac/Linux: base64 -i megatul.keystore -o keystore.txt

Откройте keystore.txt блокнотом. В Windows удалите первую и последнюю
строки (-----BEGIN/END CERTIFICATE-----). Остальное скопируйте.

=========================================================================
ЧАСТЬ 2. СОХРАНЯЕМ КЛЮЧ В GITHUB (пароли не будут видны в коде)
=========================================================================

В репозитории: Settings -> Secrets and variables -> Actions -> New repository secret

Создайте ЧЕТЫРЕ секрета:

  KEYSTORE_BASE64   — вставьте текст из keystore.txt
  KEYSTORE_PASSWORD — пароль хранилища, который придумали
  KEY_ALIAS         — megatul
  KEY_PASSWORD      — тот же пароль (если не задавали отдельный)

=========================================================================
ЧАСТЬ 3. СОЗДАЁМ СЦЕНАРИЙ СБОРКИ
=========================================================================

1. В репозитории: Add file -> Create new file
2. Имя файла (косые черты создадут папки):
      .github/workflows/build-apk.yml
3. Тело файла — всё, что ниже длинной линии
4. Внизу: Commit changes
5. Вкладка Actions -> слева «Сборка APK» -> Run workflow -> Run workflow
6. Через 5-10 минут внизу завершённой сборки, раздел Artifacts:
      megatul-release  — ПОДПИСАННЫЙ файл для RuStore
      megatul-debug    — для установки на свои планшеты вручную

=========================================================================
ЧАСТЬ 4. ЗАГРУЗКА В RUSTORE
=========================================================================

1. Зарегистрируйтесь на rustore.ru как разработчик (нужен аккаунт компании)
2. Консоль разработчика -> «Добавить приложение»
3. Загрузите файл app-release-signed.apk из архива megatul-release
4. Заполните карточку: название, описание, иконка, скриншоты (минимум 2)
5. Отправьте на модерацию — проверка занимает 1-3 рабочих дня

Идентификатор приложения: ru.yarplan.megatul

--------------------------------------------------------------------------

name: Сборка APK
on:
  workflow_dispatch:
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
      - uses: actions/setup-java@v4
        with:
          distribution: 'temurin'
          java-version: '17'
      - uses: android-actions/setup-android@v3
      - run: npm install --legacy-peer-deps
      - run: npm run build
      - run: npm install --no-save --legacy-peer-deps @capacitor/core@6 @capacitor/cli@6 @capacitor/android@6
      - run: |
          cat > capacitor.config.json << 'EOF'
          {"appId":"ru.yarplan.megatul","appName":"МЕГАТЮЛЬ","webDir":"dist","server":{"androidScheme":"https"}}
          EOF
      - run: npx cap add android && npx cap sync android
      - name: Debug APK (для своих планшетов)
        run: cd android && chmod +x gradlew && ./gradlew assembleDebug --no-daemon
      - uses: actions/upload-artifact@v4
        with:
          name: megatul-debug
          path: android/app/build/outputs/apk/debug/app-debug.apk
      - name: Проверяем, добавлен ли ключ подписи
        id: key
        env:
          KEYSTORE: ${{ secrets.KEYSTORE_BASE64 }}
        run: |
          if [ -n "$KEYSTORE" ]; then echo "ready=true" >> $GITHUB_OUTPUT
          else echo "ready=false" >> $GITHUB_OUTPUT; fi
      - name: Восстанавливаем ключ подписи
        if: steps.key.outputs.ready == 'true'
        env:
          KEYSTORE: ${{ secrets.KEYSTORE_BASE64 }}
        run: echo "$KEYSTORE" | base64 -d > android/app/megatul.keystore
      - name: Собираем подписанный APK
        if: steps.key.outputs.ready == 'true'
        run: cd android && ./gradlew assembleRelease --no-daemon
      - name: Подписываем APK
        if: steps.key.outputs.ready == 'true'
        env:
          KS_PASS: ${{ secrets.KEYSTORE_PASSWORD }}
          KS_ALIAS: ${{ secrets.KEY_ALIAS }}
          KEY_PASS: ${{ secrets.KEY_PASSWORD }}
        run: |
          BT=$(ls $ANDROID_HOME/build-tools | tail -1)
          $ANDROID_HOME/build-tools/$BT/zipalign -v -p 4 \
            android/app/build/outputs/apk/release/app-release-unsigned.apk \
            app-release-aligned.apk
          $ANDROID_HOME/build-tools/$BT/apksigner sign \
            --ks android/app/megatul.keystore \
            --ks-pass pass:"$KS_PASS" \
            --ks-key-alias "$KS_ALIAS" \
            --key-pass pass:"$KEY_PASS" \
            --out app-release-signed.apk \
            app-release-aligned.apk
      - uses: actions/upload-artifact@v4
        if: steps.key.outputs.ready == 'true'
        with:
          name: megatul-release
          path: app-release-signed.apk
