# Приём цен и статуса продажи от ERP — для разработчика мегатюль.рф

ERP отправляет на сайт цену и признак «продаётся / выключен» по каждому артикулу размера.
Нужно добавить на сайте один адрес, который принимает эти данные.

## Адрес

`POST https://мегатюль.рф/api/crm/prices`

(тот же домен и тот же префикс `/api/crm/`, откуда ERP уже забирает каталог `/api/crm/products` и заказы `/api/crm/orders`)

## Авторизация

Тот же ключ доступа, что и для каталога и заказов. ERP передаёт его в двух заголовках:

```
X-Api-Key: <ключ>
Authorization: Bearer <ключ>
Content-Type: application/json
```

Неверный ключ — ответить `401` или `403`.

## Тело запроса

```json
{
  "items": [
    { "sku": "bambuk-300x255", "price": 2490.00, "active": true },
    { "sku": "vual-400x245",   "price": 3190.00, "active": false },
    { "sku": "len-200x265",    "price": null,    "active": true }
  ]
}
```

| Поле | Тип | Что значит |
|------|-----|------------|
| `sku` | строка | Артикул размера — ровно тот, что сайт отдаёт в `/api/crm/products` (`sizes[].sku`, а если его нет — `{id карточки}-{ширина}x{высота}`) |
| `price` | число или `null` | Цена продажи в рублях, до копеек. `null` — цену в ERP стёрли: на сайте оставить старую или снять с продажи — на ваше усмотрение, лучше снять |
| `active` | `true` / `false` | `false` — товар выключен в ERP (например, закончилась ткань): скрыть с витрины или запретить заказ. `true` — снова продавать |

## Как ERP отправляет

- В запросе только изменённые артикулы: при правке цены — один, при выключении по ткани — сразу все артикулы этой ткани (может быть несколько десятков).
- Неизвестный сайту `sku` пропустите, но запрос целиком не отклоняйте.
- Повторная отправка тех же данных должна быть безопасной: просто записать те же значения.
- ERP ждёт ответ до 20 секунд.

## Ответ

Успех — любой код `2xx`, тело не важно. Удобно так:

```json
{ "updated": 2, "unknown": ["len-200x265"] }
```

Любой другой код ERP считает ошибкой и показывает у товара пометку «не ушло на сайт». Администратор может отправить повторно.

## Проверка вручную

```bash
curl -X POST "https://мегатюль.рф/api/crm/prices" \
  -H "X-Api-Key: <ключ>" -H "Authorization: Bearer <ключ>" \
  -H "Content-Type: application/json" \
  -d '{"items":[{"sku":"bambuk-300x255","price":2490,"active":true}]}'
```
