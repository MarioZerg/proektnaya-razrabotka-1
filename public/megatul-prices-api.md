# мегатюль.рф ↔ ERP: что исправить на сайте

Обмен с ERP работает: каталог `/api/crm/products` отдаётся, цены на `/api/crm/prices` принимаются (`{"updated": N}`), публичный `/api/catalog` уже возвращает цены из ERP. Проблема только в витрине.

## 1. Главное: витрина не показывает цены из ERP

Цены на страницах зашиты в код фронтенда (бандл `assets/index-*.js`):

- в массиве товаров у каждого товара `sizes: kr([2090, 2590, 3090, 3590])` — базовые цены ширин 300/400/500/600;
- функция `kr()` строит все размеры, `Ar()` достраивает ширины 200, 700, 800, а цена высоты считается как `Math.round(базовая * высота / 270 / 10) * 10`.

Поэтому для Бамбука 200×230 витрина показывает 1350 ₽, хотя в `/api/catalog` и в базе сайта лежит 1190 ₽ из ERP.

**Что сделать:**

- Брать цену размера на витрине, в корзине и при оплате **только** из данных сервера (`/api/catalog` → `products[].sizes[].price`), а не из `kr()` / `Ar()`.
- Удалить зашитые массивы цен и формулу пересчёта по высоте — ценообразование теперь ведёт ERP, в том числе разная цена по высотам.
- Цену при оплате проверять на сервере по базе, а не по цене из браузера.
- Если у размера `price = null` — не продавать его (или «Цену подтвердим», как в корзине сейчас).

## 2. Выключенные размеры

ERP присылает `active: false`, когда ткань заканчивается. Такой размер нужно скрыть с витрины или запретить заказ. Проверьте, что `/api/catalog` и страница товара это учитывают.

## 3. Метка блогера в заказе

Сайт уже ставит cookie `megatulle_ref` по ссылке `?ref=КОД`. Нужно передавать её в ERP в заказе `/api/crm/orders`:

```json
{
  "number": "MT-1024",
  "partnerCode": "anna_home",
  "partnerPercent": 10,
  "items": [{ "sku": "bambuk-200x230", "price": 1190, "quantity": 1 }]
}
```

`partnerCode` — пусто, если покупатель пришёл не по ссылке. `price` в позиции — цена, по которой реально купили.

## Справка: приём цен (уже работает)

`POST /api/crm/prices`, заголовки `X-Api-Key` и `Authorization: Bearer <ключ>`:

```json
{ "items": [{ "sku": "bambuk-200x230", "price": 1190, "active": true }] }
```

Ответ `2xx` — принято. Неизвестный `sku` пропустить. Повтор тех же данных безопасен.

## Проверка после исправления

1. В ERP поставить Бамбук 200 см = 1190 ₽.
2. Открыть страницу Бамбука, выбрать 200×230 → должно быть **1190 ₽**, не 1350.
3. Положить в корзину и дойти до оплаты → сумма та же.
