# Оболочка телевизора «Живой цех»

Полноэкранный браузер на C# (WinForms + WebView2). Открывает `https://yarplan.ru/lider` на весь экран 1920×1080.

## На мини-ПК

1. На этом компьютере соберите: в папке `desktop-kiosk` выполните `.\build.ps1`.
2. Скопируйте папку `desktop-kiosk\publish` на мини-ПК.
3. На мини-ПК в PowerShell: `.\install.ps1`.
4. В параметрах Windows включите вход без пароля (учётная запись для телевизора).
5. Масштаб экрана — 100%, разрешение — 1920×1080.

Выход: `Ctrl+Shift+Q`, PIN по умолчанию `2580` (меняется в `kiosk.ini` рядом с exe).

Страница `/lider` должна быть выложена на yarplan.ru — иначе оболочка откроет пустой экран.
