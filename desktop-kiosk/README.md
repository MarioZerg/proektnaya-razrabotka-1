# Оболочка телевизора «Живой цех»

Полноэкранный браузер на C# (WinForms + WebView2). Открывает `https://yarplan.ru/lider` на весь экран 1920×1080.

## Установщик для Windows 10

На компьютере разработки:

```
cd desktop-kiosk
.\build-setup.ps1
```

Готовый файл: **`desktop-kiosk\dist\YarplanLiderSetup.exe`**.

Скопируйте его на флешку, на мини-ПК у телевизора запустите двойным щелчком.

После установки:

- на рабочем столе ярлык **«Живой цех»**;
- при включении ПК и входе в Windows программа стартует сама;
- экран не гаснет по таймеру питания.

Удаление: «Параметры → Приложения» или тот же `YarplanLiderSetup.exe /uninstall`.

На мини-ПК включите вход в Windows без пароля, масштаб 100%, разрешение 1920×1080.

Выход из киоска: `Ctrl+Shift+Q`, PIN по умолчанию `2580` (меняется в `kiosk.ini` рядом с программой).

Страница `/lider` должна быть на yarplan.ru — иначе оболочка покажет пустой экран.

Плашка радио, дорожка, адреса волн и надпись «Нажмите на экран, чтобы включить звук» живут на сайте. После выкладки телевизор подтягивает их сам, около минуты, переустанавливать программу не нужно.

В программе зашито только одно: браузеру разрешено включать звук без нажатия. Это версия **1.2.0**. Сайт эту настройку изменить не может, она задаётся при запуске программы. В «Параметры → Приложения» она называется «Ярплан — Живой цех», версия 1.2.0.

Как понять, нужна ли переустановка. После выкладки выберите волну в Тайм-кофе и посмотрите на плашку радио на телевизоре.

- Дорожка прыгает и звук идёт: программа новая, ничего делать не нужно.
- Написано «Нажмите на экран, чтобы включить звук»: стоит старая версия, браузер звук без нажатия не включает. Радио всё равно заработает, если после каждого включения телевизора один раз нажать на экран или любую клавишу. Переустановка нужна только затем, чтобы звук начинался сам.
